# TrassTarea 📋

**TrassTarea** es una aplicación móvil desarrollada en **Android Studio** como parte de mi formación en desarrollo Android.  
El objetivo de la app es **gestionar tareas personales**, permitiendo al usuario añadir diferentes tipos de contenido y experimentar con varias funcionalidades de Android.

---

## 🚀 Funcionalidades principales

- Crear, editar y eliminar tareas.
- Adjuntar archivos a las tareas:  
  - PDFs  
  - Videos  
  - Audios  
  - Imágenes
- Organización intuitiva de las tareas.
- Interfaz sencilla y práctica, diseñada para experimentar con Android Studio y sus componentes.

---

## 🛠 Tecnologías y herramientas

- **Lenguaje:** Kotlin  
- **IDE:** Android Studio  
- **Almacenamiento:** Local (SQLite/Room o SharedPreferences)  
- **Multimedia:** Soporte para PDF, audio, video e imágenes  
- **Objetivo:** Aprender y practicar funcionalidades completas de Android, desde manejo de archivos hasta interfaces y multimedia.

---

## 💡 Nota

Este proyecto fue realizado **con fines formativos**, para practicar la integración de distintos tipos de contenido y funcionalidades de Android Studio.
